# 1.0.27 验收记录

## 本轮内容

用户提出四条：轮播笔记限两行、轮播封面加细边框、确认并删除旧统计页（等用户指定范围）、按 CODEX 审查修复五项问题。

其中前四项之外的审查修复为：

1. 校验期间熄屏或改密后，旧校验结果不再解锁。
2. 历史十二万轮摘要成功校验后重派生为目标轮数。
3. 刷新按当前形态映射请求通道。
4. 书架数据源逐级惰性回退。
5. 壁纸解码按采样后 ARGB 占用做堆预算判断。
