## 接入位置

### 根 build.gradle.kts

- `plugins` 段以 `alias(libs.plugins.detekt) apply false` 与 `alias(libs.plugins.ktlint) apply false` 登记插件版本，仅在根工程声明，不应用。
- `subprojects` 段中，对已应用 `org.jetbrains.kotlin.android` 的模块应用两个静态检查插件，使 Android 模块、库模块与 `service` 模块获得一致的检查能力。
- detekt 配置：`buildUponDefaultConfig = true`、`parallel = true`、规则文件 `config/detekt/detekt.yml`、基线文件 `config/detekt/baseline-<模块路径>.xml`、`ignoreFailures = true`。
- detekt 任务源码范围显式设置为模块内 `src/**/*.kt`，覆盖主源码、测试源码与构建脚本之外的 Kotlin 文件。
- ktlint 配置：`version = 1.4.1`、`android = true`、`ignoreFailures = true`。
- 各模块 `check` 任务追加依赖 `ktlintCheck` 与 `detekt`，`gradle check` 即可同时执行单元测试与静态检查。

### gradle/libs.versions.toml

新增版本项 `junit = 4.13.2`、`detekt = 1.23.7`、`ktlintPlugin = 12.1.2`；新增插件别名 `detekt`、`ktlint`；新增库别名 `junit`。库模块的 JUnit 测试依赖由根脚本统一补充，避免每个模块重复声明。

### config/detekt/detekt.yml

在默认规则集之上只做两项调整：`style>MaxLineLength` 上限设为 140 字符；`style>MagicNumber` 与 `complexity>LongParameterList` 首版关闭。界面布局代码包含大量尺寸常量与多参数构造函数，首版按报告形式采集，规则收窄留待后续版本逐项恢复。

## 0.9.2 切换为失败即中止

在根 `build.gradle.kts` 中完成三处修改即可切换：

1. `DetektExtension.ignoreFailures = false` 与 `Detekt` 任务的 `ignoreFailures = false`；
2. `KtlintExtension.ignoreFailures.set(false)`；
3. ktlint 告警清零（执行 `gradle ktlintFormat` 后复核），detekt 基线保留，新增告警即失败。

切换前需确认基线文件仍与代码一致；基线先行生成，新增告警才会被报告为失败。
