# 1.0.21 锁屏修复验收记录

日期：2026-10-21
版本：1.0.21（versionCode 41）
设备：P4（P4L202610130006，552×768）、S4（SA4B03CN2608081096X，480×800）

## 一、输入错误密码触发无响应

### 现象与证据

在 P4 锁屏输入四位错误密码后，界面卡住，系统日志出现：

```
10-21 20:15:14.161 390 4950 E ActivityManager: ANR in com.shuiyu.octoberrain
Dumping to /data/anr/anr_2026-10-21-20-15-06-758
Subject: Input dispatching timed out (... Waited 5004ms for MotionEvent)
```

dropbox 主线程调用栈自底向上：

```
LockOverlayView.submit
  -> LockGateImpl.createOverlay$lambda$4
  -> LockGateImpl.unlock
  -> PinHasher.verify -> verifyPbkdf2 -> derive
  -> SecretKeyFactory.generateSecret
  -> PBEPBKDF2$BasePBKDF2.engineGenerateSecret
  -> PKCS5S2ParametersGenerator.generateDerivedKey
  -> HMac.update -> MessageDigest.update -> NativeCrypto_EVP_DigestUpdate
```

ANR 期间 CPU 占用为 `34% 4297/com.shuiyu.octoberrain`，主线程处于 Runnable 状态执行摘要迭代。PBKDF2WithHmacSHA256 共 120000 轮，在 RK3326 上耗时超过输入派发时限 5 秒，系统判定无响应；进程未被杀死，用户看到界面停滞。

### 修改

`app/src/main/java/com/shuiyu/octoberrain/LockGateImpl.kt`

- 增加 `verifyScope = CoroutineScope(SupervisorJob() + Dispatchers.IO)` 与主线程 `Handler`。
- `createOverlay` 的 `verify` 参数改为回调式：在 IO 线程执行 `unlock(pin)`，结果回到主线程再交给界面。
- `LockGate.unlock` 的签名与同步语义保留，设置页等既有调用点不受影响。

`app/src/main/java/com/shuiyu/octoberrain/LockOverlayView.kt`

- 构造参数 `verify` 改为 `(String, (Boolean) -> Unit) -> Unit`。
- 提交后进入校验状态：显示「校验中…」，忽略按键，结果返回后解锁或进入错误提示与抖动。

### 真机验证

P4 上连续输入错误密码 5 次（间隔 0.5 秒）：

- 进程 PID 5042 全程存活。
- `logcat -d` 中 `ANR in com.shuiyu|FATAL EXCEPTION` 匹配数为 0。
- 第 5 次失败后配置 `failedAttempts=5`、`lockoutUntilMillis` 为当前时间加 30 秒，界面显示「尝试次数过多，25 秒后重试」。
- 使用已知 PIN 的临时配置验证正确密码：输入后约 3 秒完成校验并回到桌面，`failedAttempts` 清零。

## 二、面板样式与微读墨记保持一致

### 修改

`app/src/main/java/com/shuiyu/octoberrain/LockWallpaperView.kt`

- 无壁纸时以纸色铺底并绘制细网点：间距为高度的 0.03 倍，半径 1.2 像素，颜色 `0xFFECECEC`。
- 有壁纸时按视图尺寸铺满，仅在输入面板矩形内叠加 `0x80FFFFFF` 白纱；面板四周内缩比例为 0.0875，对应墨记 42/480 与 70/800。
- 移除原先覆盖全屏的 0xB8 白压层。

`app/src/main/java/com/shuiyu/octoberrain/LockOverlayView.kt`

- 标题文案「输入密码解锁」，字号为高度的 0.030 倍，基线位于 0.20 高度，假粗体居中。
- 四位圆点：半径 0.014 高度，间距为半径的 4.4 倍，圆心位于 0.32 高度；已输入实心黑色，未输入白底加 2.5 像素黑色描边。
- 错误提示使用 `0xFFCC0000`，字号 0.024 高度，基线位于 0.415 高度。
- 键盘为三列四行圆形按键：区域宽度为视图宽度的 0.80 倍，顶部位于 0.50 高度，高度为 0.40 倍；按键半径为单元格短边的 0.36 倍；白底加 2 像素黑色描边。
- 按键序列为 `1..9`、空白、`0`、`删除`，删除文案字号为半径的 0.58 倍；取消「确定」键，输入满四位立即校验。
- 失败时播放 9 帧、间隔 40 毫秒的抖动，位移峰值为高度的 0.018 倍，抖动结束清空输入。
