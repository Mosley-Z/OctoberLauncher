# 1.0.22 五项改造验收记录

日期：2026-10-21
版本：1.0.22（versionCode 42）
设备：P4（P4L202610130006，552×768）、S4（SA4B03CN2608081096X，480×800）
验收方式：单机完整验收后切换另一台设备复验

## 一、任务范围

本轮包含五项改造，来自两份任务文档与三条界面诉求：

1. 书架书籍展示区改为双列封面主导布局，书名作者以横向腰封覆盖封面，进度层悬浮在封面底部，右上角显示真实进度角标，不显示页数。
2. 桌面阅读组件改为极简杂志版式，五层叠放封面、左右滑动切换、中央书名、底部进度与打开按钮、右上划线笔记。
3. 锁屏界面增加应急解除密码：长按删除键十秒弹出确认，确认后清除 PIN 并进入桌面，设置项默认开启且可关闭。
4. 锁屏界面增加“选择图片”入口，经文件选择器设置锁屏背景，替换原先依赖固定路径文件的机制。
5. 应用图标替换为剪纸云雨图案，提供自适应前景、方形与圆形三套位图。

## 七、验收中发现并修复的问题

**桌面组件封面偏小。** 首版封面带按五层全展开预留宽度，实际候选两本时封面仅约组件宽四分之一。改为按可见书目数推导跨度，无笔记时不预留笔记带，封面带宽度从 143 提升到 320。

**长按删除键被移动事件取消。** `onTouchEvent` 对任意移动先取消计时，按住时轻微抖动即中止。改为删除键上的移动事件直接返回，移出按键才取消。

**设置 PIN 触发无响应。** `LockSettingsScreen` 在点击回调中同步执行 PBKDF2，主线程阻塞超过五秒。dropbox 栈显示 `setPin` 经 `PinHasher.hash` 进入 `PKCS5S2ParametersGenerator`。改为独立线程计算、主线程更新。

**书架入口不可达。** `BookshelfScreen` 只经桌面特殊项进入，设备配置把该项列入 `hiddenSpecials`。验收时临时把 `special:bookshelf` 排到桌面首位，验收后恢复原配置。

## 八、已知限制

- 桌面图标区中“图库”“微信读书”“应用商店”显示空白框，这些第三方应用自身未提供可用图标，与本轮图标替换无关；十雨桌面自身的图标已更新。
- 书架每行数量设置仍显示“1 行/页”，实际渲染固定双列，该项设置未随新布局调整。
- 备选书籍当前为三本，五层叠放的最外侧两层在设备上未同时出现，层位计算由单元测试覆盖。
- “选择图片”依赖存储访问权限，未授予时提示后返回锁屏，需在权限与授权中开启。

## 九、设备状态恢复

P4 与 S4 的配置均用验收前的备份覆盖回，锁屏摘要、盐、失败计数与壁纸路径逐字段核对一致；`desktop.order` 与 `hiddenSpecials` 恢复原值；两机 `/sdcard/Pictures/lock-test.png` 与私有壁纸目录中的测试副本已删除。恢复后两机停在原锁屏，需用原 PIN 解锁。
