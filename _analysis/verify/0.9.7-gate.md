3. `refreshPolicy` 的宿主调度与组件选择页的能力过滤仍在计划中。
4. `MediaIndex` 643 行超出单文件 600 行约定，待拆分。
5. 552×768 与 824×1648 设备不在手边，三档几何仅代码路径覆盖。
6. API 26 至 28 未实测。
7. 8.2 桌面壁纸替换路径的旧文件删除未复验，8.3 设置项补齐（图片目录、缓存清理、缩略图质量、抖动开关）尚未开始。
