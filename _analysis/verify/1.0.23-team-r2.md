# 1.0.23 第二轮改造验收记录

本轮对应六条诉求：锁屏长按提示移除、锁屏背景入口迁入实验室、API Key 单一入口、二维码录入、删除桌面卡片无障碍、负一屏书架重构。验收设备为 P4（P4L202610130006，552×768）与 S4（SA4B03CN2608081096X，480×800），两台均安装同一份 debug 包。

## 一、锁屏

- 长按删除键时长按期间只绘制删除键外圈进度弧，提示文字已移除；按住四秒截图为 `p4-hold.png`。十秒整仍弹出「是否清除密码？」确认框，文案未改。
- 锁屏面板不再绘制「选择图片」入口，`p4-lock.png` 与 `s4-lock.png` 均无该文字。
- 锁屏背景入口位于「设置 → 微读墨记 → 实验室 → 锁屏密码 → 锁屏背景」，提供「选择图片」与「恢复默认」，状态行显示背景文件名（`p4-lab-bg.png`）。
- 选择图片经自建文件选择器完成（需已授予存储访问），选图后状态行变为新文件名（`p4-lab-bg-set.png`），熄屏唤醒后锁屏背景为新图并叠加面板白纱（`p4-lock-newbg.png`）。

## 二、微信读书 API Key

- 初始化页（设置 → 微读墨记 → 设置 → 初始化）密钥输入框回填当前已保存密钥，新增「接口密钥状态：已配置（wrk-****后四位）」与整宽「扫描二维码录入」按钮（`p4-init-page.png`）。
- 点「扫描二维码录入」弹出二维码面板，显示二维码、本机地址与「等待手机提交…」，关闭后刷新输入框与状态行（`p4-qr-panel.png`）。
- 「桌面卡片」分组只剩「卡片总开关」与「重新同步卡片显示」，无障碍分组与跳转按钮已删除。
- 书架设置页与内置阅读页不再提供密钥录入入口；未配置卡片改为跳转微读墨记设置页。
- S4 密钥未丢失：`integrations.wereadApiKey` 为 28 字符且两机 `files/weread` 目录的 `assets.json`、`bills.json` 在本次验收期间持续更新；此前「丢失」的表象来自初始化页输入框恒为空，未回填已保存值。指纹书目读取自本机 `files/weread` 的本地数据，不经过密钥，因此密钥未显示时仍能读取；S4 负一屏只剩阅读指纹分区，是因为其 `desktop.negativePage.modules` 为 `["bill","fp","rank"]`，书架与最近图片在旧版本交互中被关闭后不再列出。现版本设置页会把已关闭模块一并列出并显示为「关」（`s4-desk-settings.png`），可重新开启。

## 三、负一屏书架

- P4 负一屏书架改为双列封面卡片：封面圆角裁切、腰封内书名与作者居中单行、右上角反白百分比角标、底部深色遮罩内进度条与沙漏图标、无页数（`p4-negative-shelf3.png`）。
- S4 负一屏同一模块开启后呈相同双列版式（`s4-negative-shelf.png`），480 宽下卡片文字仍单行省略。
- 卡片尺寸按分区内容宽显式二等分，高度按封面三比四换算后直接下发，避免权重测量与自定义测量互相覆盖；行间距取设计令牌的常规间距。取数、排序、点击展开浮层、`onResume` 去重与 `onPause`、`release` 取消逻辑未改。
