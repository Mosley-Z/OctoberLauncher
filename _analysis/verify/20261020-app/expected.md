# 微读墨记 App 页面真机验证断言

设备：SA4B03CN2608081096X（480×800，Android 墨水屏设备）
包名：com.shuiyu.octoberrain
安装：`_tools/verify-weread-app.sh install`（debug 包覆盖安装，数据保留；不清理 files/weread 与 files/weread_covers）
截图：`_analysis/verify/20261020-app/step-NN-描述.png`，按操作顺序递增。

## 前置

1. 安装完成后启动桌面，确认负一屏仍显示同步数据（说明 files/weread 未被破坏）。
2. 进入「设置」→「桌面偏好」页，滚动到「微读墨记」分组，确认分组标题与「打开微读墨记」入口行可见。

## 断言清单

| 序号 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 设置 → 桌面偏好 → 微读墨记分组 | 分组标题「微读墨记」、副标题、入口行「打开微读墨记」与「打开」按钮可见 |
| 2 | 点击入口 | 进入全屏页面，顶部四段页签「阅读 / 设置 / 实验室 / 待办」；实验室默认不出现 |
| 3 | 阅读页默认态 | 内层四页签「本周 / 本月 / 本书 / 洞察」；周期选择器「‹ 2026-Wxx ›」；整卡绘制（数值、柱状或日历按本周形态）；右上「刷新」 |
| 4 | 点周期左右箭头 | 标签前进/后退一个周期且卡片重绘；到达数据起始期或当前期时箭头置灰 |
| 5 | 长按周期箭头 | 标签跳一年（52 周或 12 月），仍受边界约束 |
| 6 | 点形态下拉（「本周 ▾」） | 弹出五档：本周、本月、本书、本记、待办；切到「本月」显示日历网格与摘要，切到「本书」显示封面与进度，切到「本记」显示一条划线内容与署名，切到「待办」显示待办清单 |
| 7 | 切到「本记」 | 卡片内出现「筛选」「选书」「导出」按钮与「上一条」「换一条」；点筛选可在「全部 / 只看想法」间切换；点选书弹全屏浮层（含筛选输入框、书目行、取消）；点导出生成 PNG 并提示路径 |
| 8 | 切到「待办」 | 清单显示条目；勾选切换完成（删除线）；「+ 新增」可新增；编辑可改内容；上移下移调整顺序；删除有确认 |
| 9 | 内层「洞察」页签 | 四节内容（年度概览、阅读画像、书架构成、时段分布）自绘；上下拖动可滚动，松手无惯性 |
| 10 | 实验室页 | 回设置页连续点击版本号 5 次后顶部出现「实验室」页签；页面显示数据目录文件清单、偏好快照、重开卡片与关闭实验室按钮；点关闭后页签消失 |
| 11 | 设置页三组表单 | 显示组（纸色三档、字号三档、署名日期、榜单只取书架）、卡片组（总开关、五形态池、月历样式、切换动画、尺寸档）、成就与联动组（成就开关、周月目标、保存提示、测连、帮助、无障碍入口、重开卡片、更新渠道、云端回退、安装角色）；改动后立即生效并触发卡片重绘 |
| 12 | 返回栈 | 页面内返回逐级回退（先关浮层/对话框，再回设置页分组页，再回设置首屏）；主页返回键行为正常，无崩溃 |
| 13 | 崩溃检查 | 全程 `adb logcat -d | grep -iE "FATAL EXCEPTION|wereadapp"` 无崩溃栈 |

## 数据保全

验证结束确认 `adb shell run-as com.shuiyu.octoberrain ls files/weread` 仍列出 shelf.json、book.json、stats.json、kernel_prefs.json 等文件，证明页面只读未破坏同步数据；页面写偏好只经 kernel_prefs.json 的 app_* 与既有键。
