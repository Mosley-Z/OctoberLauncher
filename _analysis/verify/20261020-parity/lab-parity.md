# 实验室页对照（P4 552×768）

## 一 微读墨记原版结构

依据 `app/src/main/res/layout/settings_layout.xml` 的 `page_lab` 子树、`inc_lab_lockscreen.xml`、`inc_lab_power.xml` 与 `shell/LabPageController.java`，实验室页为 ScrollView 内纵向容器，结构如下。

### 1 二级页签 seg_lab（SegTabView，3 段）

| 页签 | 容器 | 手机端是否装配 |
| --- | --- | --- |
| 翻页 | `page_lab_remote` | 装配 |
| 锁屏密码 | `page_lab_lockscreen` | 不装配 |
| 续航优化 | `page_lab_power` | 不装配 |

`LabPageController.bindLabTabs()` 按安装角色过滤页签，阅读器端装配 3 段，手机端只留「翻页」。

### 2 翻页页 page_lab_remote

1. 分组标题「连接方式」`lab_conn_label`。
2. 单选组 `rg_conn_mode`：关闭（默认）/ 热点连接 · Wi-Fi 直连（手机开热点）/ 蓝牙连接 · 手机当蓝牙键盘（免热点）。
3. 状态胶囊 `tv_conn_hint`：当前：关闭、当前：热点连接 · 已连接 X、当前：蓝牙连接 · 加状态。
4. 热点分支 `ll_conn_hotspot`（选热点才展开）：遥控说明；「角色」标题与横排单选 `rg_remote_role`（关闭 / 墨水屏 / 手机）；角色提示 `tv_role_hint`；手机角色折叠卡 `FoldHintView fold_role_more` 与内容 `tv_role_more`。
5. 晃动翻页块 `ll_shake_block`（仅手机角色显示）：勾选「晃动翻页（手机端）」；灵敏度行（低 / 中 / 高）；四方向各三选一（上一页 / 下一页 / 关），方向行标签 44dp；「当前映射」自证行；提示段。
6. 远程会话块 `ll_remote_session`（角色非关闭显示）：「开始遥控」「结束遥控」两按钮等宽；状态行；「空闲自动断开：」输入框（96dp）+ 单位「秒」；说明两段；互斥提示；「打开系统无障碍设置」按钮。
7. 蓝牙分支 `page_lab_bt`（连接方式选蓝牙才展开）：页顶简介；启用勾选、不支持警示、状态行、断链恢复引导、配对引导、「让本机可被发现（配对用）」按钮与说明、测试翻页行（上一页 / 下一页）与说明、两张折叠卡（配对要点、连接不上怎么办）、墨水屏端说明。
8. 本机晃动块 `ll_shake_local_block`（与连接方式无关，常驻该页）：标题；折叠卡（作用说明与「一起翻页」提示）；启用勾选；翻页方式单选（点击边缘 / 横向滑动）；竖屏说明；四方向各三选一；自证行；无加速度计警示。

### 3 锁屏密码页 page_lab_lockscreen

简介；「启用锁屏（默认关）」勾选；「4 位数字密码」输入框与「保存密码」按钮；状态行；「锁屏背景」路径输入框与「载入背景图」「恢复默认」两按钮；状态行；背景存放提示；无障碍依赖警示。

### 4 续航优化页 page_lab_power

简介；权限状态行；「在电脑上执行这一行：」命令文本与「复制命令」按钮；步骤说明；三项勾选各带说明（关掉「开放网络可用」提示 / 关掉界面动画 / 关掉时钟屏保）；「打开系统电池优化页」按钮与说明；Shizuku 进阶说明。

## 二 十雨现状

入口：设置 → 微读墨记 → 顶部「实验室」页签（`feature/weread-app/.../ui/WereadLabPage.kt`，189 行）。页面为单栏滚动，无二级页签。

未展开态：标题「实验室」；「实验内容尚未展开。」；说明「在设置页连续点击版本号五次即可展开，展开后显示数据目录与偏好快照。」；版本行。

展开态：标题；数据目录路径；数据文件清单（文件名、大小、修改时间，逐行）；「偏好快照」标题与以「标签 + 值」右对齐的十六行（安装角色、仅一页模式、启用墨台、刷新绑定、阅读成就提示、周目标档位、月目标档位、导出图纸张档位、导出图字号档位、导出图显示署名、导出图显示日期、榜单只取书架、卡片总开关、形态池掩码、月历热力图、实验内容）；操作按钮行（重开卡片、收起实验内容）。

## 四 结论

一、页签骨架需补齐为三段：翻页（本机能力内保留「分组标题 + 单选 + 勾选 + 折叠卡」形态，内容可裁剪）、锁屏密码、续航优化。
二、远程连接、蓝牙、摇一摇三组明确可裁剪，页签与分组标题保留，避免视觉与操作层级与原版断裂。
三、锁屏密码组与续航优化组需补齐；无障碍入口可从远程会话块移到页尾通用按钮。
四、实验内容门禁与「展开后显示偏好快照」为十雨自有扩展，可保留；数据目录与文件清单属排障信息，建议折叠到「数据文件」分组下。
