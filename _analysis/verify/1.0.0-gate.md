## 六 真机冒烟

设备 S4，序列号 `SA4B03CN2608081096X`，Android 11，480×800、219 dpi。安装 `app-release.apk`（R8 混淆包）后执行：

- 冷启动：`am start -W TotalTime 1053 ms`；日志 `OctoberRain: page=桌面 create=19ms stack=0`；截图 `_analysis/verify/shot-1.0.0-release.png`。
- 负一屏：左滑后日志 `page=负一屏 create=22ms stack=1`，书架卡片与「最近图片」卡片同时渲染，截图 `shot-1.0.0-negative.png`。旧配置只有 `bookshelf` 时同一入口只出现书架卡片，证明模块列表来自配置而非硬编码。
- 文件页：点「全部图片」后日志 `page=文件 create=29ms stack=2`，目录、缩略图、排序与翻页正常，截图 `shot-1.0.0-files.png`。
- 查看器与编辑页：Debug 包上点击卡片首图进入查看器（`page=图片查看 create=18ms`），旋转、裁剪、五档滤镜与另存均可用，截图 `shot-1.0.0-viewer.png`。
- 锁屏：安装后首次启动出现四位 PIN 界面（截图 `shot-1.0.0-unlock.png`），与配置 `lock.enabled` 一致。
- 内存与故障：桌面 PSS 30761 KB、RSS 127096 KB；负一屏 PSS 31392 KB、RSS 129424 KB；日志无 `FATAL EXCEPTION`、`ClassNotFoundException`、`SerializationException`。

冒烟期间对设备配置做过两处写入：把 `negativePage.modules` 补为 `["bookshelf","negative_files"]`，关闭 `lock.enabled` 以便自动化点击。验证结束后写入测试图片已删除（`/sdcard/Pictures/AAAtest` 与 `v1-image.png`），配置保留 `modules` 两项与 `lock.enabled=false`，`pinHash` 原值未改。
