# 十雨桌面 V1.0.0

面向 Android 墨水屏设备的首个正式版本。

- 普通与沉浸阅读桌面，支持横竖屏、分页应用、逐页组件、壁纸和图标自定义。
- 提供多款时钟、待办周历、微信读书书架、阅读统计、本书及笔记组件。
- 内置文件管理与离线阅读，支持文本、PDF、Markdown、EPUB、压缩包及受资源预算限制的 Office 文档预览。
- P4 可通过现有无障碍服务从自绘状态栏下滑展开系统通知；返回桌面时保持全屏布局。未启用服务时使用真实系统栏回退。
- 接入 GitHub Releases 更新，支持后续配置国内清单源与相同安装包的下载镜像；下载后验证大小与 SHA256。

最低 Android 8.0；本轮功能验证以 Android 11 墨水屏设备为主。

本版本使用新的长期正式签名。之前使用测试签名的安装不能直接覆盖升级，请先在应用内导出备份，再卸载测试版并安装正式版，最后导入备份。以后正式版本沿用同一签名，可正常覆盖升级。
