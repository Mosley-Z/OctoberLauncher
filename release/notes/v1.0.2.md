# 十雨桌面 V1.0.2

本次更新集中修复墨台交互、阅读资产价格与首次设置体验。

- 修复墨单按钮、视图切换、算法选择及录价弹层在重绘后状态丢失的问题，完善长内容滚动和空态操作。
- 阅读资产支持独立手动增量刷新与二次确认后全量重拉，保留手动价格、隐藏书目和失败缓存；接通笔记价格索引，明确区分未知价格与免费书籍。
- 阅读资产和阅读指纹默认启用；保留已有用户显式关闭的设置。未选择指纹书目时先显示“阅读指纹”标题。
- 首次引导权限页缩小间距，退出前列出未设置权限并二次确认；P4 将无障碍置顶，提示其对状态栏的影响。
- 分离系统设置与十雨设置，修复 S4 系统设置入口，调整设置卡片、辅助文字和阅读进度显示。
- 修复桌面组件长按、横滑和图片切换之间的冲突，减少不必要的分钟重读和封面失败重绘。
- 完善最近图片读取；首次引导启用微信读书后，普通桌面默认显示本月阅读组件。

Android 8.0 及以上。V1.0.0/V1.0.1 正式版可直接覆盖升级并保留数据；旧测试签名版本请先导出备份，再迁移到正式版。

已完成 P4 首次引导重点路径实测，其他改动已有 S4 部分交互与内核合成回归证据。真实账号书价覆盖率、全部权限开启后的引导及长墨单完整手势场景未全部实测；接口未提供价格的书籍仍显示未知。
