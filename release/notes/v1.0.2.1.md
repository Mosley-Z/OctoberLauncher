# 十雨桌面 V1.0.2.1

- 修复“十雨设置”自定义图标被默认品牌图标覆盖的问题。
- 根桌面收到 BACK 时保持前台，兼容实体 HOME 映射为 BACK 的设备。
- S4 从十雨打开的系统设置首页支持通过现有无障碍服务返回十雨，需开启“十雨桌面状态栏与按键兼容”；系统按键映射保持不变。
- 减少从系统设置返回桌面时的小组件强制重读与重复暂停/恢复，保留内容变化、跨日及手动刷新。
- 修复封面下载非200或空响应被误判成功而触发重试的问题，后台和息屏不再启动新的界面封面预取。

S4 实体键返回及组件恢复观感已通过用户手验；完整构建检查与单元测试通过。夜间待机耗电仍在排查，本版本不宣称已解决整夜掉电问题。

Android 8.0及以上，正式签名版本可直接覆盖升级并保留数据。
