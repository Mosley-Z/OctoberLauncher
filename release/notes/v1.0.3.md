# 十雨桌面 V1.0.3

- 文件图片查看器新增“设置为”：S4休眠壁纸、关机壁纸及同时设置，需开启十雨无障碍服务。
- 图片编辑新增“本机尺寸”：按屏幕比例裁剪、拉伸到屏幕尺寸、等比居中并添加白至黑可调背景；处理结果另存，原图保留。
- 修复1:1、4:3等裁剪比例选择不立即生效，以及拖动时比例失真的问题。
- 修复原盘书架点击“微信读书打开”无响应，兼容已有书架快照。
- 内置产品站点国内备用更新源；GitHub获取失败自动回退，下载包继续验证版本、大小和SHA-256。
- 移除检查更新页常驻历史日志，仅发现新版本时弹出该版本更新说明。
