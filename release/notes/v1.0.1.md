# 十雨桌面 V1.0.1

本次更新改善首次设置、微信读书同步与墨水屏使用体验。

- 完善首次引导和权限设置，统一微信读书 API Key，修复同步忙碌时请求遗漏及失败状态保存。
- 墨单使用同轮阅读统计派生；调整时间组件预览比例、微读初始位置与横屏默认布局。
- 图片轮播统一为分钟，最低1分钟；旧轮播数值按同数值分钟迁移。
- 后台和息屏暂停页面计时，恢复前台更新当前画面；取消重复的分钟整页刷新。
- 定时全刷默认关闭，保留已有显式设置；自动同步仅更新当前数据，并限制请求次数、超时和重试频率。
- 保留手动完整同步。历史统计、全库资产和笔记可通过手动同步补齐，已有缓存保留。

Android 8.0及以上。V1.0.0正式版可直接覆盖升级，保留数据；旧测试签名版本请先导出备份，再卸载测试版、安装正式版并导入备份。
