## 需求与证据回读

1. 最终入口：组件库提供时钟/月历/待办周历/图片/微信读书等有效组件；usage和宿主切组件手势入口移除；“关闭”表示选关闭组件，不是返回选择页。
2. 控件位置：周历左年月右新增、第二行星期箭头、第三行日期箭头；图片手势设置归图片组件；微信读书形态按钮保留。
3. 显示归属：周历仅有日期的7天待办；沉浸今日量归账号而非当前书籍；关闭组件后全页应用区；其他页方向宫格与首页独立。
4. 字段/消费者：clockFace保留旧ID；calendar保留ID；待办同源；方向宫格、图片方向、周历起始星期字段由本卡冻结，追桌面/预览/美化/备份导入消费者；旧widgetSwitchGesture及widgetCycleIds不再驱动轮换。
5. 迁移：新字段缺失与显式旧选择分开；usage选中清退为关闭并补位、保留有效当前组件及原应用顺序；正常加载和备份导入同规则。图片手势新默认关闭，不套用旧组件切换手势；不改无关用户状态。
6. 验收触发：按下表在最终同一源码/APK复核，规则单测、工程门禁和实体设备分别记录；截图、命令和未覆盖附新验收记录。
