# 十雨桌面使用说明

适用于当前十雨桌面。点击目录进入章节；章节中可上下滚动，顶部返回或系统返回先回目录，再返回关闭说明。本文离线可用。

## 01 快速开始与主要入口

十雨是面向墨水屏的安卓桌面。安装后按系统提示选择十雨为主屏应用；如没有提示，可到系统的默认应用或主屏应用设置中选择十雨。系统菜单名称可能因设备不同而变化。

首次引导先选择宫格或列表，再选择是否连接微信读书。不需要微信读书可直接跳过，普通桌面和本地文件阅读仍可使用。已完成引导的用户升级后不会重复进入引导。

桌面的“设置”打开十雨设置中心：“微读墨记”查看阅读数据、待办和微读设置；“桌面偏好”管理外观、布局、托盘、权限与备份；“美化与图标”管理图标和美化主题。网络、蓝牙、电源等卡片进入设备系统设置。

遇到残影可点击顶部时间或刷新环进行整屏刷新。点击顶部状态栏留白可打开快捷托盘；系统返回优先关闭当前菜单、覆盖层或弹页。

## 02 手机扫码录入微信读书 API Key

先在手机获取并复制 Key：在手机微信中打开 weread.qq.com/r/weread-skills，按官方提示完成登录与获取。此处仅提供文字方法；十雨二维码用于把已复制的 Key 录入墨水屏。

首次引导中选择启用微信读书，点击“手机扫码录入本机”。已有用户可进入“设置→微读墨记→设置→初始化”，点击“扫描二维码录入”。

让手机和墨水屏连接可互通的局域网。用手机扫描墨水屏上的二维码，在手机页面的输入框粘贴完整 Key，再点“提交密钥”。保持墨水屏录入页面打开，回到设备查看接收和保存结果。二维码不包含你的 API Key。

首次引导收到 Key 后先保存，再尝试验证连接。保存成功与在线验证成功是两件事：网络异常或 Key 无效时按提示重试；稍后配置可进入普通桌面。在初始化页也可直接粘贴或输入 Key，选择“保存并返回”，再用“测试连接”确认。

扫码页为临时会话，关闭、离开或过期后请重新生成。二维码无法打开时检查同网、访客网络、热点隔离或防火墙；不能互通时改为在墨水屏本机输入。不要把包含 Key 的截图或文本公开分享。

## 03 普通桌面与应用整理

点击应用图标或名称启动应用，左右滑动切换应用页。第一页在组件外继续右滑，可进入已启用的负一屏“墨台”。列表桌面还支持上下滑动翻页。

长按应用打开操作菜单，可按当前入口提供的选项更换图标、置顶或隐藏等。继续按住进入整理模式，拖动调整顺序；按返回退出整理。不同应用与内置入口的菜单项目可能不同。

隐藏只影响桌面展示，不会卸载应用。重新显示可到“设置→桌面偏好→桌面与布局→交互→管理隐藏应用”。应用安装、卸载或权限变化后，返回桌面刷新应用列表。

## 04 宫格、列表与横屏布局

进入“设置→桌面偏好→桌面与布局”。宫格的“首页”和“其他页”分别用一行“列×行”控件调整；自动档按可用空间计算，放不下的数值会按屏幕容量限制。首页组件和应用共同使用可用高度。

切换为列表后，可分别调整首页与其他页条数，再选靠左、居中或靠右，以及左右边距。列表参数与宫格参数分别保存。应用间距由版面自动分配，不再提供旧的行间距、列间距调整。

“显示应用名称”统一控制普通桌面名称展示。隐藏名称后仍可点击原槽位；透明图标再隐藏名称会使位置难以辨认，建议先记住常用入口，并使用整理模式或沉浸抽屉寻找应用。

在本页“阅读桌面→模式、方向与常用应用”中选择竖屏、横屏90°或横屏270°。普通横屏首页左侧放组件，右侧应用竖列排列；方向设置会保存，返回桌面后检查显示与触点。

## 05 沉浸本书与应用抽屉

进入“设置→桌面偏好→桌面与布局→模式、方向与常用应用”，将模式改为“沉浸本书”。首次成功连接微信读书后也可在引导中选择沉浸模式。

沉浸模式固定显示“本书”，不会随普通桌面的组件轮换。竖屏常用应用在底部一行，横屏在右侧竖栏。可设置常用应用数量、选择项目并上移、下移或移除；实际数量会按屏幕空间调整，留空时使用桌面前几项。

点击常用栏最末端的应用抽屉入口，查看全部可用应用。抽屉保留可辨识图标和名称，可用上一页、下一页翻页，点击应用启动；返回键或“返回本书”关闭抽屉。

抽屉中的“退出沉浸”恢复普通桌面，原有宫格或列表布局仍保留。之后可从同一设置入口重新进入沉浸。尚未配置微信读书或没有本书数据时，按画面提示连接或刷新。

沉浸桌面继续使用你设置的桌面背景和自定义图标。书名可简化显示套装或版本信息，完整名称仍在选书列表中。统计卡显示缓存中的今日阅读、读完书籍和连续阅读；缺失或日期不明确的数据用“—”表示，不以书架数量替代。

## 06 小组件、切换手势与本记展开

通过桌面组件选择入口选择时钟、图片、微信读书等组件；选择图片组件后，再长按桌面组件区进入组件库，通过“图片组件设置”选择、更换或清除图片。未选择图片时也可直接轻触桌面图片组件选择图片。图片轮播间隔仅作用于图片组件。

“模式、方向与常用应用”在普通模式下提供组件与顺序设置。添加至少两个组件，调整轮换顺序，并将切换手势设为右滑、上滑或关闭；默认右滑。只有一个组件时不发生轮换。

切换普通组件时，从标题或留白区域滑动。微信读书封面区域的滑动用于换书，正文区域保留内部滚动，不用于切换整个组件。切换直接显示结果，没有过渡动画。

普通桌面本记正文溢出时，点击“展开”，阅读层覆盖到下方末行应用名称附近，显示更多文字。长文可继续上下滚动；底部上一条、换一条、收起保持可用。点击收起或按返回恢复应用区，展开期间先由阅读层处理触摸。

短文放得下时不显示无用的展开按钮。横屏或可用高度不足、覆盖无法增加阅读空间时，会转入独立本记页。切换页面、组件、方向或离开桌面时，临时展开层会关闭。

## 07 负一屏墨台与书架

在普通首页的组件外右滑进入已启用的墨台；左滑或按返回离开。墨台中的浮层或设置打开时，返回先关闭它们。

在墨台设置中选择需要的分区。书架标题栏提供微信读书或本地书源、行数及刷新等操作。

微信读书书架和桌面本书共用阅读数据。书架刷新后再回本书可查看更新；断网时已有缓存可继续查看，不代表远端数据已经同步成功。阅读进度与最近顺序以成功刷新后的数据为准。

点击微信书封先打开页内书籍浮层，再按其中的打开入口前往阅读；本地书交给十雨内置阅读器。使用本地书源时按页面提供的入口选择文件或刷新，不依赖微信读书 Key。

## 08 微读墨记的阅读数据与本记

从十雨设置中心进入“微读墨记”。主界面提供阅读、设置、待办等入口；阅读项的下拉可选择本周、本月、本书、本记、待办和足迹。

本周、本月查看对应周期的阅读统计；本书展示当前或备选书籍、进度和阅读信息。侧封面用于选中书籍，封面滑动用于换书；中央封面或“打开”入口用于打开选中的书，设备需有能处理对应阅读链接的应用。

本记可按页面菜单筛选、选书、切换记录，查看划线与想法。需要导出时使用页面提供的导出入口，并检查实际保存位置和生成内容。只有成功获取过的笔记才可离线查看。

数据刷新需要有效 Key 和可用网络；本地展示、账号验证与数据刷新是不同操作。若界面显示空数据，先核对 Key、所选形态和书目，再进行刷新，不必反复重新安装原微信读书 App。

## 09 微读自定义与待办

“微读墨记→设置”中的初始化页用于 Key、连接测试、怎么用和更新入口；自定义页用于微读卡片的外观、内容和对应选项；锁屏密码页提供相关密码与背景设置。

修改选项后按页面提示保存或返回。微读卡片与桌面卡片共用相关设置，但沉浸模式始终固定本书；普通桌面的组件选择和轮换顺序在十雨“桌面与布局”中管理。

待办页分列表和已完成，可新增内容、日期与时间，点击条目编辑、勾选完成，通过排序按钮上下调整。删除前会确认。日期时间字段不等于已设置系统闹钟提醒；待办与阅读统计分开，切换阅读形态不会删除待办。

## 10 图标、桌面壁纸与美化主题

长按应用或内置入口，选择“更换图标”。可选择自定义图片、使用透明图标或恢复默认。透明状态会隐藏图像和边框，保留原位置与触点；它不等于隐藏应用或卸载应用。选择图片会替换透明状态，恢复默认会清除该入口的自定义图标状态。

在“设置→桌面偏好→外观与主题”中管理桌面壁纸、字体、图标外形、对比度等。壁纸可按页面选项调整显示效果；墨水屏上建议使用清晰的黑白图案，并留出文字对比空间。

“设置→美化与图标”可安排应用图标并保存主题，主题库提供应用、导出和删除。当前美化主题包含图标图片、透明状态、名称显示、布局参数及桌面壁纸资源，可导出为单个.ttp文件，再从“导入”选择文件。

保存时可选首页或全部。首页范围保留其他页的容量与未涉及应用图标；壁纸、名称显示等属于整体外观。跨设备应用列表不同，应用主题后请检查图标对应情况。本机应用顺序按本机保留。

桌面壁纸与锁屏背景不是同一设置。厂商的休眠、关机画面尚未作为本轮通用功能提供，不要把桌面主题中的壁纸当成设备关机画面。

## 11 快捷托盘、通知与刷新

点击顶部状态栏留白打开托盘；普通宫格还可在组件外向下滑打开。列表的上下滑动用于翻页，组件内部也有自己的手势，因此从这些区域下滑不一定打开托盘。

托盘提供当前可用的快捷开关、通知与系统操作。Wi-Fi、蓝牙等可长按进入相应系统设置；部分系统操作需要授权或由系统确认。按返回关闭托盘，或在托盘内容已经滚到顶部时继续下滑收起。

通知显示需要通知读取权限，在“桌面偏好→权限与授权”中开启，并在“通知展示”中调整展示方式。没有授权时，不会因为桌面上有托盘就自动获得通知内容。

点击状态栏时间或刷新环进行整屏刷新。整屏刷新可能短暂闪黑，这是墨水屏清理残影的表现；不需要靠频繁重启应用清理普通残影。

## 12 文件管理、相册与图片

桌面“文件”入口打开文件管理。点击文件夹进入，使用返回、上一级、上一页或下一页导航；列表和图标视图按页面提供的切换入口使用。文件操作、选择模式与普通浏览模式的按钮不同，确认当前模式后再保存或返回。

文件菜单可按名称、时间、大小或类型排序，切换升降序和隐藏文件显示。图片查看器可左右滑动切图，菜单提供分享、旋转、详情和量化等操作。

图片编辑提供裁剪、90°旋转、滤镜和对比度等，保存为新的PNG；按页面选择导出尺寸，检查Pictures/十雨桌面或实际提示位置。不要把仅预览的画面当成已经保存，自选文件夹以当前页面是否提供可用操作为准。

非图片文件由内置阅读器按实际格式打开。也可从其他应用用“打开方式”或分享把文件交给十雨；来源必须允许十雨读取，云端或可撤销授权的文件可能需要重新选择。

保存和导出优先使用可用的系统或内置文件界面。若设备没有可用的保存界面，部分导出会落在应用私有导出目录；以成功提示和具体功能显示的路径为准，不默认所有文件都在Download。

## 13 本地阅读、全文搜索与书签

支持文本、PDF、Markdown、EPUB及ZIP浏览，并提供受设备能力限制的DOCX、表格和PPTX阅读。不同格式的排版与可用设置不同，复杂Office文档不保证与电脑软件完全一致；受保护、损坏或过大的文件可能无法打开。

阅读器工具栏提供上一页、阅读设置和下一页；音量键也可翻页。进入“阅读设置”查看当前格式可用的字号、显示、目录、搜索或书签等选项，未提供的项目表示该格式当前没有该操作。

全文搜索会扫描当前文档，按结果定位；可用时通过后续匹配在结果间移动。搜索位置与原阅读位置分开，取消搜索后再继续阅读。表格搜索按匹配单元格计数。

可用格式支持添加和查看书签。阅读进度、书签与具体文件来源关联；重新打开同一文件可继续阅读，复制成另一份、换来源或来源版本变化时不保证沿用原位置。

常用格式操作：DOCX可切正文或原版式；Markdown可切排版或纯文本（切换从头）；EPUB可选章节目录；ZIP可进入目录、选择内部文件及文件名编码，不能嵌套打开ZIP。

PDF可使用页面提供的放大缩小、视口移动、裁边或整页显示，不提供全文搜索或OCR。表格可选工作表并定位行列；PPTX可切原版式和文字提纲。阅读设置中的全刷间隔可按设备和残影情况选择，0为关闭定期间隔全刷。

本地书架的最近阅读可回到已打开文档。若文件移动、删除或读取授权失效，按提示重新选文件；不要在未知PIN或系统权限问题下反复尝试修改原文件。

## 14 锁屏、安全与权限

“设置→桌面偏好→锁屏与安全”管理十雨的锁屏、密码和相关选项；微读设置中的锁屏密码页也提供对应入口。设置密码时完成确认，检查返回后状态，再测试能否正确解锁。忘记密码时按设备实际提供的恢复方式处理。

十雨的覆盖锁屏不等同于系统级设备加密，锁屏背景也不等于厂商休眠或关机图片。未知原密码时不要通过覆盖旧设置来尝试解锁。

“权限与授权”列出通知读取、无障碍、悬浮窗、存储、使用情况访问等所需授权。按需要开启，不用的权限可保留关闭；系统版本和厂商限制可能影响可用项目。

通知、悬浮球、锁屏覆盖、使用统计等功能可能分别需要不同权限。设备限制后台运行时，可按页面入口检查电池优化与后台管理；改完系统授权后返回相关页面复查状态。

## 15 备份、更新与换机

进入“设置→桌面偏好→备份与恢复”导出配置备份，恢复前先保留当前备份。完整恢复会覆盖相应配置，恢复主题只处理该入口约定的外观内容；它和“美化与图标”的.ttp主题包不是同一个操作。

配置备份不携带本机API Key、PIN摘要和盐。换机后请重新配置凭据和必要权限；配置备份也不等于已经备份所有原始书籍、照片或云端阅读数据，这些文件需另行保管。

十雨和内置微读功能一起更新，不必另装原微读墨记App。在十雨“检查更新”或微读初始化页的“检查十雨桌面更新”中操作，下载和安装按系统提示完成。

升级后原有已完成的引导不会重复。图标、主题和备份从外部导入后，检查目标应用、壁纸、布局与文件读取权限是否符合新设备。

## 16 常见问题与排查顺序

二维码打不开：先确认手机和墨水屏可互通，再重新生成未过期的本机二维码；访客网络、热点隔离、防火墙可能阻断访问。官方获取地址只帮助你取得Key，不会自动把Key传入十雨，仍需在本机录入页粘贴提交。

Key已保存却没有书籍：先测试连接，确认Key仍有效，再核对网络与所选书架来源，进行数据刷新。保存成功不代表账号验证或书架刷新已经成功；断网时旧缓存不会自动成为新数据。

组件滑动没切换：确认处于普通模式、序列至少有两个组件、手势没有关闭；从标题或留白起手。本书封面用于换书，本记正文用于滚动，沉浸模式固定本书。

本记看不到展开：短文无需展开；横屏或空间不足时可能打开独立本记页。已展开后用正文滚动，点击收起或返回，切换桌面或组件也会关闭临时阅读层。

应用图标不见了：检查透明图标、名称开关和隐藏应用设置。透明图标仍占原槽位；可从整理模式、可见名称或沉浸应用抽屉找到入口，再恢复默认图标。

文件打不开或原进度丢失：检查原文件是否仍在、授权是否有效、格式与文件大小是否受支持；复制件或换来源可能视为不同文件。先保留原文件再重新选择，不要用删除原文件排查。
