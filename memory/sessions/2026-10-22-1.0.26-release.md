# 1.0.26 交接：最近在读排序、轮播底部放大与负一屏设置排版

## 本轮诉求

用户提出三项：书架与轮播按最近在读排序、书籍轮播底部文字按钮放大（后改为只放大最下面一行 10%）、负一屏设置排版美化；并要求把代码同步到 GitHub。

## 关键实现

- 排序：新增 `core/common/.../WereadRecentRead.kt`（`parseRecentReadTimes`、`sortByRecentRead`），`KernelDataSourceImpl.readTimes()` 与 `KernelWereadReader` 各自按文件 `lastModified` 与长度缓存解析结果，再交给共享函数排序。
- 数据源：`KernelDataSourceImpl.rawShelf()` 三级优先 `loaderShelf()` → `disk()` → `networkShelf()`；`KernelDataLoader.shelf()` 读的是 `shelf.json`，`assets.json` 只用于排序键。
- 定位：`loadData` 固定 `carousel.reset(cards.size, BOARD_FIRST_BOOK_INDEX)`，删掉 `restoredIndex`；`book_pick` 仍记录用户换书的结果，但不再决定打开时显示哪本。
- 字号：`WereadBoardFrame.INFO_TEXT_SCALE = 1.1f` 只驱动 `infoSize` 与进度条厚度。
- 设置页：`DeskSettingsView` 增加 `addGroupTitle`、`addHint`、`newRow`、`touchControl`、`buildStepper`，分组留白与 40dp 触控区落地。
