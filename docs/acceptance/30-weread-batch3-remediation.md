# 微读墨记功能集成：第三批修复记录

日期：2026-10-21。第三批从 1.0.18 开始，开发包为 1.0.19，最终与第四批一起交付 1.0.20 / code 40。前两批及其他开发者已有修改均保留，没有修改原 WereadMoji 仓库。

## 范围及需求调整

本批处理 R10 模块开关与排序、R11 指纹偏好、R12 壁纸导出、R13 人工编辑持久化。

用户在本批明确：不需要导入原 App 数据，所有阅读数据由微信读书接口取得，移植计算和展示规则即可。因此撤下原 App 迁移入口、导入服务注册、配置回写服务及自动回写接线；默认独立同步，旧 `imported` 兼容为 `synced`，保留本地缓存与“仅本地缓存”模式。历史迁移实现/测试暂留，不作为产品使用前提。

## 最终实现

### 模块开关和顺序

- `DeskModulePolicy` 是五个内置模块的共同规则。按配置原顺序去重，真实过滤显示掩码；全部关闭后不补回默认模块。
- `moduleOrder` 保留关闭模块的位置；关闭后仍可在设置中找到入口并重新开启，也可先排序再开启。
- 墨台内设置和外部负一屏设置共用策略；外部扩展模块不丢失，`desk` 容器不作为第六张可切换卡片展示。
- 内核宿主显式转换十雨配置位和实际内核位，不把单分区渲染位当作用户启用状态。
- 墨台恢复时比较相关配置快照，外部修改的模块、顺序和墨单样式可以生效；无关锁屏变化不触发额外重建。

### 阅读指纹

- 候选采用原版笔记索引口径，支持嵌套/平铺元数据、去重及未同步正文标注；不再混入整个未读书架。
- 支持搜索、最多 50 本多选、清空草稿、已选计数、确认与取消。300 行显示上限如实标注，可搜索完整候选。
- 集合持久保存，明确区分未配置与主动清空；重建内核直接读取集合，不再调用单本临时覆盖接口。
- 真实读取 16–19 字号设置；设置选书独立加载，不依赖列表页已经测量，也不要求先启用指纹显示。

### 人工价格与移出书目

- `WereadDeskEditsStore` 使用实际内核读取的 `menu_prices.<bookId>` 与 `menu_hidden.ids` 键，兼容已有旧格式。
- 确认录价先落盘，成功后更新内核；保存失败重载撤销临时状态并提示。清空手填价和明确免费保持不同含义。
- 修复内核旧隐藏列表为空时提前返回、漏合并当前隐藏项的问题；首次移出同样落盘。隐藏写完整快照；恢复写空快照，避免旧文件或旧配置重新带回已恢复书目。
- 价格/隐藏状态不属于联网同步数据，普通同步保留；编辑成功刷新其他分区，当前操作页面保持自己的状态。
- k6 没有公开当前价格键盘书目，固定兼容桥集中读取两个分区的 `pad` 字段，并以实际 jar 契约测试约束；发布规则保留内核成员。

### 导出

- 使用实际 k6 公开分区常量：账单 0、资产 1、指纹 3；旧传值 2 会被内核兼容为资产，已修复。
- 指纹图纸使用原版 480×800，避免拉伸字形；账单/资产沿用现有 1080×1920 渲染入口。指纹在墨台列表使用完整高度并交给外层滚动，不套用资产窗口的 320dp 上限，避免小屏截掉后半张。
- 全屏预览在显示对话框后设置尺寸，图片等比适配。保存成功提示使用真正写入的文件名。

## 真机暴露的性能问题及修复

本批没有以自动测试通过作为结束。P4 大书库实测发现首载分钟级等待，以及长按后输入超时 ANR，分三层处理：

1. 偏好读取原先逐本解析约 510 KB JSON。现在按文件时间、大小与文件标识缓存；本实例写成功立即失效，外部替换、删除和恢复也能失效。
2. 录价面板和拖动原先在 `onDraw` 直接调用内核，仍会在主线程计算整库。现在每分区单一串行队列拥有内核，绑定、测量、渲染、命中、滚动、长按、录价与壁纸统一排队，UI 只显示结果帧。重载/释放以代次隔离旧回调并关闭线程，高度变化同时请求子视图重测。
3. 移到后台后仍有数十秒延迟。核对实际源码发现 `excerptOf` 对每本可见书重复 `loader.notes(0)`，每次重读 227 本笔记。增加页面级笔记缓存，`invalidateAll()` 统一失效；摘录优先级、字段、金额和排序规则不变。

第三层使用可复现宿主内核补丁：`libs/weread-kernel-1.3.2-k6-host1.jar`，SHA-256 `ef586cc8b1343a0c78f16fb972ff11e24ec8775e57638a5ab101663518ea7fa6`。原 k6 保留，只有 `DeskData.class` 内容改变，其他 zip entry 字节及公开 API 不变。源码、来源摘要、构建校验脚本及真实 Android 合成数据探针见 [内核补丁说明](../../tools/weread-kernel-host/README.md)。
