# 微读墨记功能集成：第四批修复记录

日期：2026-10-21。交付版本：1.0.20 / code 40，与第三批最终修复共同验收。

## 范围与最终行为

### R15：唯一锁屏

实验室不再写无人消费的 `kernel_prefs lock_*`。启用、PIN、自动锁定和背景直接使用十雨桌面唯一锁屏服务及壁纸仓库，与宿主设置共用状态。

- 四位数字 PIN 二次确认后由宿主生成 PBKDF2 摘要，后台计算，确认配置写入后反馈；保留已有密码和其他锁配置，不用旧实验室摘要覆盖宿主密码。
- 无密码时不能启用；可以立即锁定，自动锁定有独立开关，关闭时明确说明实际行为。
- 清除密码经过确认，并关闭锁屏。背景载入异步交给唯一仓库，成功才提示；恢复默认不改桌面壁纸及量化设置。
- 真机发现服务 `isLocked=true` 仍没有覆盖层，原因是 Activity 未挂状态观察器。补齐创建时订阅、主线程同步覆盖层和销毁时解除，避免仅依赖恢复前台时检查。
- 作用范围准确标为十雨桌面内锁，不要求悬浮窗权限，也不冒充系统设备锁。

### R16：完整 App 导航

App 阅读页始终保留本周、本月、本书、本记、待办与足迹；桌面启用池只控制桌面卡片。没有新增第二套形态选择偏好。

### R18：统一更新

内置微读功能和内核随十雨桌面一起升级，不单独安装原 App。移除只有存值、没有执行消费者的正式/Beta 通道和云端备用源开关。显示实际宿主版本，“检查十雨桌面更新”进入宿主更新页，使用宿主配置的清单地址；本批未进行下载、安装远端更新或发布操作。

### 用户明确要求：删除远程翻页模块

删除 `WereadLabFlipPage`、翻页页签及其回调；实验室只保留锁屏密码和续航优化。没有保留占位模块、连接/角色控件或虚假的已连接状态。

同时移除没有运行消费者的本机手机角色入口、手机键盘说明及只服务旧翻页诊断页的版本号五连击入口。历史偏好字段保留以兼容解码，不再代表当前提供的产品能力。
