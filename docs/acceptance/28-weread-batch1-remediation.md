## 范围与实现

本批处理审查报告 R02、R04、R05、R09、R14，以及 R03 的自动在读选择部分。

- 宿主与内容层使用同一个 `WereadGatewaySyncProvider`。逐书调用 `/book/getprogress`，直接保存整数百分比，累计秒数优先使用 `readingTime`；未知进度保留为 -1，失败保留历史缓存。
- 自动本书按书架 `readUpdateTime` 选择最近阅读，包含刚读完的书；历史书逐本补查后同时更新书架和资产。资产不再从周期 Top10 反推。逐本持久化结果，24 小时内未变更的历史书使用缓存，最近本书每轮补查。
- 笔记索引完整分页，划线与个人想法分别获取；规范化书名、作者、价格、进度及章节字段。正文逐本保存，传输失败后中止该类后续请求，下轮可续补。索引分页失败不替换旧索引。
- 迁移不再因已有目录而拒绝。导入前备份，暂存新目录并保留旧目录，规范化和配置提交失败时回滚。成功后切换为导入来源，普通刷新不覆盖导入数据。相同迁移摘要仍保持幂等。
- 同步与迁移共用互斥门，防止目录替换时仍有网络同步写入；取消、启动失败、结果处理及解除挂接释放入口。完成后失效消费者缓存并通知重绘。
- 同步结果区分完整和部分成功；笔记计数标注为本轮更新的文件数，命中缓存时为 0 不代表笔记库为空。
