# S4/P4 外部录像光学阶段测量

日期：2026-10-23；分析者：Codex URI 子任务，独立只读原片分析。两机各确认40个光学事件：20次有效A/B反相翻页、随后20次顶部时间控件触发的 `manualFull`，没有用操作日志的存在代替视频事件。

主定义为**格内画面首次超过5%变化阈值，到进入最终画面5%容差并持续稳定250ms的时间**。每组N=20，nearest-rank P95取升序第19项：S4翻页116.5ms、manualFull 902.6ms；P4翻页90.7ms、manualFull 489.6ms。这是本棋盘与本录像条件下的光学阶段观测，不包含触点/CLI请求至首个光学变化的等待，也没有给这四组预设2s或200ms达标线。

## PTS与方法

1. ffprobe逐帧读取 `best_effort_timestamp_time`，ffmpeg以 passthrough 顺序解码；两机PTS数量与解码帧数严格一致。S4帧间隔中位16.633ms、P95 16.645ms、最大33.311ms，存在一次较长间隔；P4中位18.133ms、P95 18.134ms、最大19.800ms，平均帧率约56.35。使用真实PTS差，不能用帧号除以标称60。
2. 先人工查看t20预览。初轮固定格心受摄影位移影响，P4出现伪事件、S4第17次有伪长尾；该轮结果已作废。最终以手机外框/屏幕外静态特征做LK跟踪及RANSAC相似变换，必要时用静态界面特征重新定位；棋盘不参与运动拟合。逐帧变换、特征数和原始ROI序列保存在 `*-registered.npz`。没有通过最大化棋盘对比度来“修正”物理过渡。
3. 原48个格内候选中，最终两机统一采用第4–6行的24格，每格中心9×9采样中位灰度。避开时间、页码、按钮、标题、棋盘边界、底部紫色反光及上部反光变化；配准后的多格位置已在接触图人工核对。不是整屏最慢像素测量。
4. 每帧24格共同均值被扣除，以削弱自动曝光的加性亮度漂移；保留棋盘对比度变化。每事件以前稳态及后稳态各一段的逐格中位数为参考，后稳态为粗事件结束后0.4–0.9s。差异定义为24格的绝对灰度差中位数；主阈值取 `max(4灰度级, 最终黑白对比度×5%)`。这是一项可复现的区域光学定义，不是宣称识别了首个变化粒子。
5. 起点为连续两帧超过前稳态阈值的首帧；终点为首次回到最终参考容差内、并持续至少250ms的首帧（250ms确认窗口不加进时长）。粗检测仅用于划分相隔数秒的操作，实际端点均由上述规则重算。前20事件的棋盘符号均反转，后20事件均离开并返回同一符号，两个设备均40/40核对。
6. P95为nearest-rank第 `ceil(0.95×20)=19` 项，不插值。另以3%阈值重算敏感性（同时影响变化起点与稳态容差），没有追加新录像样本或把阈值差当统计置信区间。

## 边界与人工复核

- 每个起止帧均量化到真实PTS。两端相邻帧间隔之和的保守误差界，S4最大33.379ms、P4最大36.400ms；该界只描述帧采样，不涵盖未知曝光/滚动快门/阈值误差，也不是P95置信区间。
- 人工查看两机配准后的代表接触图：S4事件1、9、17、21、23、24、40；P4事件1、7、8、21、28、35、40，包含首尾、P95或最大值、摄影位移伪长尾修正点。图中“before→first→mid→stable”与反相/黑屏恢复方向一致，绿色框落在格内，未触及紫色反光。
- 接触图按真实PTS用ffmpeg精确seek提取；曾发现OpenCV按帧号seek在P4变帧率源上取错代表图，已改正并重新人工查看。最终测量CSV来自全帧顺序解码，本身未使用OpenCV随机seek。接触图只供人工核对，不是替代CSV的计时来源。
- S4单个首次配准失败帧处于视频开头、远离全部操作，已保留NaN而未虚构采样；测量的80个事件均有完整起止和250ms确认窗口。两机没有从操作列表排除慢样本，也没有把摄影伪事件计为产品动作。
- CLI请求开始/返回和S4 monotonic日志只对应操作次序与软件提交端点，不是物理手指接触时间。本结果不能与软件open/turn耗时简单相加，也不能算完整触点到光学完成延迟。

## 证据与复现

同目录本地证据：

- `S4-video-metadata.json`、`P4-video-metadata.json`：原片摘要、实际帧数/PTS与候选ROI。
- `S4-registered.npz`、`P4-registered.npz`：逐帧PTS、格内亮度、摄影配准参数及特征数；`*-optical.npz`为保留的初轮固定ROI，不作最终指标。
- `S4-events.csv`、`P4-events.csv`：各40行，全局序号、动作、起止0基帧号/PTS、阈值、最终/初始对比度与5%/3%时长。
- `*-settling-summary.json`、`*-frame-error.json`、`*-signal.csv`：分组P95、每事件实际帧误差与全片信号。
- `S4-contact.jpg`、`P4-contact.jpg`：上述已人工复核代表边界。
- `analyze-optical.py → register-roi.py → measure-events.py → settling.py → contact-sheets.py`：仅本地分析脚本，ffmpeg/ffprobe 8.1.1及已有Python cv2/numpy/Pillow，最终运行退出0；原片及二进制不纳入产品或Git。

操作关联原证据为 `s4/optical-actions.json`、`s4/optical-monotonic.txt` 与 `p4/physical-action-events.jsonl`、`p4/physical-readerperf.txt`。本报告补上此前缺少的本轮真实外部光学阶段数据；厂商波形接口、整个屏幕逐像素最慢完成及跨文档/温度完整光学矩阵仍未由本次有限实验验证。
