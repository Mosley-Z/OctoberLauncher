# 微读墨记迁移保真：第二批修复记录

日期：2026-10-21。版本：1.0.18 / code 38。接续第一批 1.0.17 的未提交工作树。

## 范围与实现

本批处理审查报告 R01、R06、R07、R08、R17，以及 R03 的手动选书部分。原 WereadMoji 仓库仅作只读对照。

### 成就与绑定刷新

- `WereadAchievement` 共用原版档位和设置键：完美/狂暴周为 10/25 小时，月为 40/100 小时，自定义小时换算分钟。桌面与内置阅读页共用剩余/达成文案，只对当前周/月显示；兼容旧分钟目标，显式关闭优先。
- 新增 `WereadRefreshRequest` 和按形态刷新的服务。周、月、本书请求当前形态，再补拉勾选的周/月/本书；同项不重复。历史周期刷新使用实际所选起点，绑定项使用当前期。本记只强制同步笔记正文，待办只重读本地且不要求密钥。
- 读取原版 `bind_targets` 位掩码，并兼容当前独立布尔设置；设置保存同步镜像位掩码。刷新失败保留已有缓存及原成功时间，完成后通知消费者重载。
- 本书定向刷新仅补所选书及最近书，不预热全部资产；书架、本书和资产复用同一批真实进度。

### 共享选择与待办

- `book_pick` 持久保存手动本书。App 与桌面读取同一选择，选中后补查该书；清空选择时从完整书架的 `readUpdateTime` 选择自动书，离线时也不沿用上次手选的 `book.json`。
- 本记以完整索引抽取，正文按书加载。默认、想法、选书分别持久化槽位；默认池沿用原版 40 条随机批次、当天稳定、跨天推进和真实访问历史。选书池保持本地原序，全部条目可达，不再永久截为 200 条。
- App 选记书目同步桌面；“只看想法”保持 App 专属。桌面进度直接读取共享选择状态，避免依赖 App 曾经绘制留下的旧计数。默认池总量保留原版索引原始记录计数口径，选书池使用合并后真实条数，随机批次数不冒充全库总量。
- 桌面仅向内核提供未完成待办；绘制列表与点击 ID 均来自过滤后的同一顺序。重载时重建磁盘装载器，避免已完成或已清空记录从旧缓存重新出现。

### 切换与双机走查发现的问题

- 桌面按 `switch_mode` 选择循环或列表；两者统一使用启用池，选择后持久保存。列表复用内核选择器，支持滚动和关闭。
- 修正内置选书/选记底板比例：`sheetRatio` 表示底板占比，顶部应为 `height * (1 - sheetRatio)`。原实现把 70% 当成顶部位置，两台设备都只露出很少书目。
- 核验 k6 `BookPicker.scrollBy` 的方向与 1 逻辑像素阈值，修正上滑方向，累积细小位移，并在抬手时补齐可能未处理的最后一段移动。
- 组件已开始拖动时取消桌面长按任务，修复 S4 慢拖列表时误打开组件选择页的问题。
- 修正 App 周期解析时抓取时间与周期起点的参数顺序。
