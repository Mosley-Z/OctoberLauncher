## 任务目标

请分析我当前 APP 的书架模块代码，并将书架中“书籍展示区域”的 UI 重构为以下样式。

### 重点说明

- 书名和作者信息**不是放在书籍封面下方**
- 它们是一个**横向白色“腰封”信息条，直接覆盖在书籍封面上**
- 阅读进度条区域也**不是独立放在卡片底部外侧**
- 它是一个**悬浮覆盖在封面底部的细长信息层**
- **不显示页数信息**
- 仅显示阅读进度条和右下角的小图标/状态图标
- 右上角保留黑色百分比角标

本次修改的目标是：
**将当前书架重构为“封面主导 + 浮层式信息覆盖 + 极简黑白视觉”的双列书架 UI。**

------

## 一、整体布局要求

### 1. 书架布局

- 每行显示 2 本书
- 双列等宽布局
- 卡片之间保留统一间距
- 页面左右保留适当边距
- 所有卡片高度统一
- 在不同屏幕尺寸下保持整齐稳定
- 不允许横向溢出
- 不做瀑布流

### 2. 卡片整体形态

每本书是一个完整的圆角卡片，主体几乎全部由封面构成。

卡片特点：

- 圆角矩形
- 圆角约 12–16px
- 有细边框或弱描边
- 不使用厚重阴影
- 整张卡片以书籍封面为主视觉
- 封面占据几乎整个卡片区域
- 所有覆盖元素都叠加在封面之上

------

## 二、卡片结构（这部分最重要）

请严格按以下结构实现：

### 区域 A：书籍封面（主背景）

- 书籍封面作为整个卡片主视觉
- 封面图片铺满整个卡片主体区域
- 使用 `cover` 模式裁切
- 不允许图片拉伸变形
- 卡片四周圆角裁切生效
- 所有信息层覆盖在封面之上，而不是排在封面下方

------

### 区域 B：书名信息腰封（覆盖在封面中下部）

在封面中下部覆盖一条白色横向信息腰封。

#### 腰封样式要求：

- 白色或浅灰白底
- 横向贯穿卡片宽度
- 位于封面下半部分偏下的位置
- 像纸质书腰封一样，直接“压”在封面上
- 与封面形成明显层次
- 腰封有细边框或上下分隔线
- 不需要做成独立大卡片区块

#### 腰封内容：

1. 书名
2. 作者名

#### 文字要求：

- 书名位于上方，水平居中
- 作者位于书名下方，水平居中
- 书名字体颜色较深
- 作者颜色较浅
- 两者均限制单行显示
- 超出使用省略号
- 保持紧凑排版
- 整体视觉效果应接近参考图中的“封面上横向贴了一张信息条”

------

### 区域 C：底部阅读进度层（悬浮覆盖在封面底部）

在卡片封面底部覆盖一层阅读进度信息区域。

### 重要要求：

- 该区域**浮在封面上**
- 不是卡片外部的底栏
- 不是独立白底信息块
- 是一个贴近卡片底边的覆盖层

#### 包含内容：

1. 横向阅读进度条
2. 右下角状态图标（可保留类似沙漏图标）
3. 可选的底部暗色半透明背景，用来提高可读性

#### 阅读进度条要求：

- 细长圆角进度条
- 显示实际阅读进度
- 已读部分深色
- 未读部分浅色或白色
- 外层细边框清晰
- 视觉上应与参考图类似，位于底部信息层中央偏左
- 不显示百分比文字在进度条内部

#### 右下角图标要求：

- 位于进度层右下角
- 可使用线性风格小图标
- 若项目当前已有状态图标逻辑，则复用
- 不新增无意义交互

#### 明确要求：

- **不要显示页数**
- **不要显示“337 p.”、“7920 p.”之类的文字**
- 如果当前实现里已有页数字段，本次 UI 中不要展示

------

### 区域 D：右上角阅读进度角标

在卡片右上角叠加一个黑色角标，显示阅读百分比。

#### 角标要求：

- 黑色底
- 白色文字
- 类似参考图中的“书签/徽章/盾牌”造型
- 顶部贴住卡片右上角
- 下方带小尖角
- 百分比文字加粗且居中
- 示例：`28%`、`52%`、`0%`

#### 数据要求：

- 百分比必须来自真实阅读进度
- 显示为 0–100 的整数
- 与底部进度条保持一致

------

## 三、视觉风格要求

整体视觉严格参考附件图片，关键词如下：

- 黑白极简
- 封面主导
- 浮层式信息覆盖
- 腰封设计
- 紧凑布局
- 细边框
- 几何清晰
- 低装饰感
- 阅读器/电子书书架风格
- 更像“封面卡展示”，而不是普通商品列表卡片

### 禁止做成以下样式：

- 封面下方另起一个大白块放书名
- 常规电商卡片布局
- 大面积阴影卡
- 彩色渐变设计
- 页数文字标签
- 底部信息区脱离封面独立存在

------

## 四、功能约束

本次只允许修改 UI 和布局表现，必须保留原有业务逻辑：

- 点击书籍进入阅读器
- 书籍封面加载
- 书名和作者数据绑定
- 阅读进度计算
- 书架列表加载
- 排序/筛选/搜索（如果已有）
- 长按菜单或管理功能（如果已有）
- 数据缓存和状态管理
- 分页或现有加载机制

### 严禁：

- 随意改动后端接口
- 修改数据结构
- 重写无关模块
- 为了适配 UI 而破坏现有交互逻辑

------

## 五、实现建议

请优先按以下思路实现：

1. 将单本书抽成独立书籍卡片组件
2. 卡片采用相对定位容器
3. 封面作为背景主层
4. 书名/作者腰封使用绝对定位覆盖在封面中下部
5. 阅读进度层使用绝对定位贴在底部
6. 百分比角标使用绝对定位贴在右上角
7. 处理长书名、省略、封面加载失败、进度为空等情况
8. 保持滚动性能，避免重渲染
