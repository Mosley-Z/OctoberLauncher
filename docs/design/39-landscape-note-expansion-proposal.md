# 横屏本记向右展开方案

**用户于本轮明确“确认，请实施”，本说明已获实施授权并接入当前源码。** 仅适用于横屏，竖屏原逻辑不变。关联 [UX133](../../task/TASK-UX-133-desktop-followup-corrections.md)及[本轮验收](../acceptance/2026-10-24-ux133-approved-landscape.md)。文字结构图不代表设备通过，当前结果以验收记录为准；不新增持久配置或数据。

## 参照的竖屏行为

现有竖屏本记由桌面宿主承载临时阅读层：保留原字号、行距和首行锚点，向下借用应用区展示正文；正文过长可竖向滚动。底部保留源书/章节及上一条、换一条、收起，阅读层拦截全部触摸，避免点到下方应用；Back关闭。组件提供当前笔记数据及换条动作，正式独立笔记管理页不受影响。

## 横屏目标

仅当当前笔记正文发生截断时，句尾显示 `… 展开▶`；短文不显示入口。横屏底部只保留上一条、换一条，展开入口位于句尾。没有容纳行而隐藏正文同样算溢出，但必须有可见尾部才能放置入口，不把入口画在不可见区域。

收起态书名/章节保持当前横屏 C 本记中位于正文之前的原位置，不借修改展开搬动原信息。

点击后，当前条笔记原文按增加后的宽度重新换行，段落、字号与行距保持。正文左侧起点、上边界及下边界保持，纸面右边界跟随首页应用区右界，临时覆盖两列应用，不再取整页最大右界；应用区收回时阅读层右界相应收回。正文右侧留白独立计算，不能用文字留白缩短纸面的覆盖范围。左书签和日期基线不变；普通横屏侧栏承载标题与刷新，正文不随其重排而移动。不跳新页，应用布局只按用户明确的位置调整生效。

复用竖屏的是阅读层、滚动、关闭和换条逻辑，不能直接套用竖屏坐标或字号。横屏以现有 C 正文的实际首行锚点、字号、行距和原文为依据，右扩仅按新增宽度重新排版，不改收起态 C 布局；此处保留的“原字号/行距”指当前横屏原样式，竖屏自身完全不变。

扩宽后正文仍过长，沿用现有竖向滚动。展开层底部保留竖屏已有的来源信息及上一条、换一条、收起动作，按横屏空间排布。收起或Back恢复原布局；翻页、切换组件、旋转或离开桌面时关闭阅读层。展开期间拦截全部触摸，右侧应用不接受穿透点击。

空态或换条后重新计算溢出及可展开范围；原数据来源不变。如果右侧没有可增加的安全空间，入口不可触发，不以跳页替代。没有新增持久配置。

## 前后结构示意

以下仅为文字结构图，不是已渲染设计稿；比例不代表最终像素。

```text
收起（横屏）
┌─────────────────────────┬───────────┐
│ 书签  日期／刷新         │ 原应用区  │
│      源书／章节          │           │
│      当前笔记正文        │           │
│      ……截断… 展开▶     │           │
│      上一条  换一条      │           │
└─────────────────────────┴───────────┘

展开（横屏，同一桌面临时阅读层）
┌─────────────────────────────────────┐
│ 书签  日期／刷新（位置不变）         │
│      当前笔记按新增宽度重新换行      │
│      左起点及上下边界保持；可竖向滚动│
│      源书／章节                      │
│      上一条  换一条  收起            │
└─────────────────────────────────────┘
       └────右扩，临时覆盖原应用区────┘
```

## 验收范围

- P4 90°/270°横屏：短文无入口，长划线、想法及混合正文仅溢出时出现句尾入口；段落、字号、行距和固定边界保持。
- 扩宽后仍过长的正文可滚动；源书/章节及上一条、换一条、收起可用，换条重算，不触发下方应用。
- Back、收起、翻页、换组件、旋转和离开均恢复原应用布局；无右侧空间时不能触发展开，不跳页。
- S4 竖屏原阅读层、向下展开、滚动、换条和关闭行为保持。
