# 十雨 · 纸页书桌设计稿

2026-10-23，待用户确认。任务：[UX001](../../task/TASK-UX-001-reading-desktop-proposal.md)；行为契约：[具体方案](../../docs/design/37-reading-desktop-proposal.md)；设备边界：[可行性记录](../../docs/acceptance/2026-10-23-desktop-feasibility.md)。

## 打开与交付范围

直接用浏览器打开 [index.html](index.html)，无需安装或联网。总览提供10个页面/状态的缩略图及“单独查看”；可点击本记展开/收起、设置、抽屉、宫格/列表、加减和开关。

书名、封面、笔记正文和统计均为本轮合成数据。图标与封面由HTML/CSS/内联SVG绘制，无外来品牌图标或用户正文；字体使用系统微软雅黑/宋体回退。页面不连接微信读书、不保存Key、不实际导出主题或启动Android应用。二维码显示、账号验证、换笔记等非设计验证动作未接入，不用虚假成功提示冒充实现。

## 方向与依据

北极星：让书占据视线，让应用随手可达。

品类为墨水屏阅读桌面。直接参考是用户提供的沉浸图和当前项目源码；本轮没有另外获取两个外部竞品截图，不做“已完成竞品视觉验证”的声明。

| 参考中的可见元素 | 取舍及十雨表达 |
| --- | --- |
| 大时间居中占据上部 | 时间靠左，与十雨的页边对齐；主视觉仍给书封 |
| 多本封面前后叠放 | 保留一个主封面与两侧提示，减少灰阶与边缘重叠 |
| 大面积灰色统计卡 | 改一行数据与细竖线，减少灰底和占高 |
| 底部五个固定功能入口 | 改用户常用应用＋固定抽屉，适合Launcher职责 |
| 混合手写图标 | 使用同笔画线性图标，与设置分隔线呼应 |
| 原悬浮卡展开 | 宿主内白底阅读层；固定收起位置，不透点应用 |

视觉取安静、精确对齐、中等密度、轻边界、偏书页的文字层级；不用纸纹、米色、阴影、渐变来假装“纸感”。黑白为主，灰色仅用于封面层次与次要信息。大字时间、宋体书名、无衬线操作文字构成层级。真实Android渲染必须沿用项目tokens并测字号/dp，网页像素不直接等同设备dp。

## 页面清单

1. 沉浸：分钟时钟、书封、进度、统计、常用应用/抽屉。
2. 普通：缩小本书组件，保留4×2应用与页码。
3. 偏好：列×行各一行，切列表时替换成条数、对齐和边距。
4. 首启：微信读书可选，明确稍后开启。
5. 本记收起：三行摘要及展开动作。
6. 本记展开：正文区域变大，应用隐藏在白底阅读层后，收起按钮固定。
7. 抽屉：应用名称列表，显式退出沉浸。
8. 图标/主题：透明作为图标状态，明确主题包含项。
9. Key连接：获取与录入分开说明，不使用伪造可扫二维码。
10. 横屏结构：左阅读主体、右竖列应用。为未来布局设计，不是当前APK截图。

## 交互、动效与评审

没有动画。页面切换、本记收展、选择与开关均直切，按用户墨水屏约束覆盖通用技能的动画建议。静态设计不证明真实EPD刷新性能。

主Agent做了三轮视觉检查，不打分、没有独立评审：第一轮发现沉浸书封挤到日期、普通桌面进度与应用区交叠、引导插图尺寸失控；第二轮缩减次要内容与封面、条件显示列表控件；第三轮修正竖排书名换列、本记底部名称漏出及覆盖区键盘穿透。最终检查代表状态截图并查看工具报告。

减法：移除普通桌面重复章节行；统计从灰卡改一行；删除重复密钥说明；移除“此处用于确认…”类原型内部提示。无效产品按钮未伪造成功提示，范围在本说明中披露。

可交互部分为浏览器内临时状态，不测试持久化。主Agent通过浏览器检查本记收展、列表条件显示及抽屉进退；设备产品流程仍待业务实现。
